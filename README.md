# BULOG Website

Website statis sederhana untuk halaman utama, tentang kami, pelayanan publik, berita, dan kontak BULOG.

## Menjalankan project

Gunakan terminal di folder ini, lalu jalankan:

```powershell
python -m http.server 3000
```

Setelah itu, buka:

```text
http://localhost:3000/
```

Atau jalankan file `start.bat` di Windows.
